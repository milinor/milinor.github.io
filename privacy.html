Privacy Policy

Last updated: November 10, 2026

About This Application

CachyOS Rclone Drive is a personal application using rclone to access the owner's Google Drive files from a CachyOS Linux computer.

Google Drive Access

The application accesses Google Drive files only as authorized by the Google account owner. This includes reading and streaming music files for personal playback.

Data Storage

Authentication credentials and configuration are stored locally by rclone. Files may be temporarily cached or downloaded during use.

Data Sharing

This personal integration does not sell user information or intentionally disclose Google Drive data to unrelated third parties.

Data Security

Google OAuth is used for account authorization. Access can be revoked through Google Account security settings.

Data Retention

Locally stored credentials, cached files, and downloaded data can be removed by the account owner.

Contact

Questions about this personal integration can be directed to its owner through the GitHub profile .
